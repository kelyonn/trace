# Trace brand assets

| File | Use |
| --- | --- |
| `trace-mark-dark.svg` / `trace-mark-light.svg` | The cube-and-trace mark alone, for dark and light backgrounds |
| `trace-logo-dark.svg` / `trace-logo-light.svg` | Mark plus the `trace` wordmark (PNG copies alongside) |
| `trace-icon.svg` | Rounded app icon, also served as the web favicon |
| `trace-icon-square.svg` | Square, unrounded icon for stores that apply their own mask |
| `trace-social.svg` / `.png` | 1200 x 630 social preview card |

The wordmark is drawn as paths, so it needs no font. The amber (`#f5a524`) is the app's selection colour; the cube faces are the neutral ink/paper tones.

The web app serves PNG favicons, the Apple touch icon, PWA icons and `og-image.png` from `apps/web/public`. They are generated from these SVGs.
